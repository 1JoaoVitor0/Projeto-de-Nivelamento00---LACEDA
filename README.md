# 📊 People Analytics: Análise de Turnover e Retenção

Análise estratégica de dados para mapear as causas do *turnover* e propor ações de retenção de talentos.

### 🎯 Entregáveis do Repositório
* 📓 **Jupyter Notebook (`.ipynb`):** Script completo de tratamento de dados, análise exploratória e validação técnica das hipóteses. Também possui os códigos que geraram os gráficos.
* 📄 **Relatório (`.pdf`):** Documento completo que detalha os processos de análise, apresenta as conclusões e propõe o plano de ação para mitigar a taxa de evasão elevada da organização.
* 🖼️ **Pasta de Gráficos (`/graficos`):** Acervo com todas as visualizações de dados exportadas em alta resolução.

---

## 🚀 Destaques da Análise

* **Turnover Global:** **27,2%**, concentrado nos níveis **Júnior** e **Pleno**.
* **Ponto de Ruptura:** Sobrecarga acima de **45 processos** e **35h extras/mês** alavanca os desligamentos.
* **Setor Crítico:** Departamento **Trabalhista** (turnover de **43,5%** nos Juniores).
